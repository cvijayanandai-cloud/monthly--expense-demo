# Monthly Expense Calculator

A beginner GitHub project using fictional expense figures in Indian rupees.

## Files
- `expenses.csv`: sample expense categories and amounts. Edit this file to try new figures.
- `expenses.py`: Python program that adds the amounts.

## Run
Install Python 3, download this repository, and run:

```bash
python expenses.py
```

No extra Python packages are required.

## Expected output
```text
Monthly expenses: Rs. 10,000.00
Expense categories: 4
```

## Learn GitHub
A repository holds project files. A commit records a saved change. A branch lets you try improvements separately. A pull request proposes changes for review before merging them into main.

To practice, edit an amount in expenses.csv and commit the change with a short explanation. The History view shows the earlier versions.

All figures are fictional. This public repository contains no personal financial records.
